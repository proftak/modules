# What is this?

This is a reading sequence of content modules that together stand in for a
textbook in CISP 310, Computer Architecture and Organization. Every entry links
to a module that can also be read on its own, so the sequence is an ordering of
independent pieces rather than a single work broken into chapters.

The course it follows is described in the official course outline as follows:

> This course covers the organization and behavior of real computer systems at
> the assembly-language level. Topics include the mapping of statements and
> constructs in a high-level language onto sequences of machine instructions, as
> well as the internal representation of simple data types and structures.
> Numerical computation is examined, noting the various data representation
> errors and potential procedural errors.

# How to read it

Read the parts in order. Each module opens with an "About this module" block
naming its prerequisites and what it sets out to do, so you can check whether
you are ready for it before starting, and you can enter the sequence part-way
if the earlier material is already familiar.

Part 1 is general study skill material that is not specific to this course.
It applies to any class, and you are welcome to skip it.

# Assumed background

This sequence depends on four modules that it does not itself include. Read
them if the material they cover is not already familiar.

* [0279: Boolean Operator](../0279/mdModule.html) — assumed by 0281
* [0298: D-flipflop and other basic memory devices](../0298/mdModule.html) — assumed by 0299
* [0432: TTP assembly language basics](../0432/mdModule.html) — the TTP instruction set
* [0434: TTP programming](../0434/mdModule.html) — writing TTPASM programs

Working knowledge of C or C++ is assumed throughout the assembly language
material, and the circuit modules assume access to Logisim.
